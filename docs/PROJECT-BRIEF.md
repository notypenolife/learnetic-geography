# Geography project brief

Build a separate interactive geography resource in the Geography folder using the user-supplied HTML.

The first activity explores elevation and height difference through linked 3D terrain and contour-map views, two observation points, elevation comparisons and an explanation.

The user requested English throughout. All interface and teaching text, including canvas labels and PNG exports, is translated into natural English. Creator attribution remains as Xiao Xiao Xiao Bai, with English social-platform names. The Three.js MIT licence, terrain model, calculations and chapter-0 restriction remain intact.

The lesson runs in the Vite/React host and can also be opened directly as a standalone HTML file. Student age and syllabus are unspecified. This project is independent of the CPU resource and has no hosted deployment.
